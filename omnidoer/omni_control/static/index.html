Security

Secret destination: Secret Broker. Not sent to Agent/LLM context, MCP return values, logs, or DOM observation.

Challenge destination: Challenge Relay / target website. OmniDoer does not bypass CAPTCHA/MFA/Passkey/WebAuthn/3DS.

Human Takeover destination: controlled browser. Agent paused. User in control until Continue Agent.

Registration Handoff: if a site needs a new account, the registration page is proxied to you. You complete registration directly; OmniDoer does not automate fake or bulk registration, and registration secrets/challenges are not sent to the LLM.

Security

Secret destination: Secret Broker. Not sent to Agent/LLM context, MCP return values, logs, or DOM observation.

Challenge destination: Challenge Relay / target website. OmniDoer does not bypass CAPTCHA/MFA/Passkey/WebAuthn/3DS.

Human Takeover destination: controlled browser. Agent paused. User in control until Release Control.

Registration Handoff: if a site needs a new account, the registration page is proxied to you. You complete registration directly; OmniDoer does not automate fake or bulk registration, and registration secrets/challenges are not sent to the LLM.

Chat / Task

Submit work to the local OmniDoer task queue. The Control Client does not call OpenAI APIs or models directly; Codex reads tasks through the MCP tool control.next_user_task.

Do not enter passwords, verification codes, card numbers, private keys, or other secrets here. Use Credential Request or Challenge Request panels for sensitive input.

Human Takeover

Agent paused. User in control. Release Control when finished. Touch, scroll, type, and key events are sent only to the controlled browser. Registration pages can use the same handoff so users complete signup themselves.
